Why a semantic role should not point directly to a raw hex value
When a semantic role points directly to a raw hex value instead of a primitive palette token, it breaks the chain of inheritance and isolates that element from systemic updates. As demonstrated by the inconsistent UI, updating the core brand color only cascaded to the roles that maintained proper aliasing. This proves that strict token referencing is mandatory to maintain a single source of truth and ensure scalable, predictable design updates across an entire application.
