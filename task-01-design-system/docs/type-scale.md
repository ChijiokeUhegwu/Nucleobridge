# Typography System

## Overview

The typography system uses five roles: Display, Headline, Title, Body, and Label. Each role has three sizes: large, medium, and small, giving 15 text styles in total.

A line-height multiplier of **1.5** is used consistently across all five roles. Line height is calculated as:

**Line height = Font size × 1.5**

This provides a consistent vertical rhythm across the interface. The same multiplier is used for headings, body text, and labels to keep the system simple and predictable.

## Type Scale

DM Sans is used throughout Nucleobridge's typography system to create a clean, modern, and approachable interface. As a product where users need to navigate information, understand instructions, and interact with interface elements efficiently, Nucleobridge benefits from a typeface that supports clear reading and quick scanning. DM Sans provides a contemporary sans-serif style that works across headings, body text, and smaller labels, helping maintain a consistent visual identity throughout the interface. Its range of weights also supports the typography hierarchy, allowing display text and headings to stand out while body text and labels remain functional. This makes DM Sans a suitable choice for Nucleobridge's goal of delivering a coherent, accessible, and easy-to-use digital experience across desktop and mobile screens. ## Letter-Spacing Rationale

Negative letter spacing was chosen to make text more compact and improve visual cohesion, particularly in headings and larger display text. The spacing becomes less negative as text gets smaller, avoiding excessive compression at small sizes.

Display Large uses -3.5px letter spacing to tighten the large text without relying on the default spacing recommended in the Material Design documentation.
