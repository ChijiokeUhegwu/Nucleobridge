# Generic Error Responses & User Enumeration Defence

If authentication error responses are distinguishable (such as returning "User not found" versus "Incorrect password"), an attacker learns with certainty whether a targeted email address is registered on the platform, enabling automated user enumeration. With a confirmed list of valid accounts, the adversary can eliminate guesswork and concentrate automated credential stuffing, dictionary attacks, or targeted spear-phishing campaigns exclusively on registered users.
